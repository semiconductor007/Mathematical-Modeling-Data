## 证据冲突裁定

1. Kimi K3：采用官方 API 文档。`max_completion_tokens` 默认 131,072、最大可设为 1,048,576，实际输出上限为上下文窗口减去输入 token；废弃二级来源 33K。
2. GLM-5.2：采用智谱官方模型页的 128K，并以 131,072 tokens 入表；废弃第三方部署页面的 262K。

GLM 官方 HLE 评测披露的 `max generation=163840` 属于开源评测 harness 参数，不代表第一方 API 产品上限；该参数只保留在 Benchmark `test_setting` 中，不进入模型 API 元数据。

上述两项均已按“第一方模型/API 文档优先于第三方聚合页”的规则完成裁定，冻结数据中不再存在未决数值冲突。
